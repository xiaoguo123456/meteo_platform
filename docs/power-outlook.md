# 新能源态势模块

新能源态势位于“站点预测”之后，是面向新能源调度和运维的区域级视图。它把精选风电、光伏站点的四模型功率预报聚合到同一条时间轴，给出出力区间、模型一致性和短时爬坡事件。

## 页面能力

- **区域功率态势**：站点按经纬度投影到区域图，风电和光伏使用不同颜色，选中站点后联动时间轴。
- **全国功率预测**：P10、P50、P90 分位区间分别对应四个模型结果的下界、中心值和上界，时间轴支持未来 24 小时浏览。
- **爬坡预警**：按未来 6 小时内的绝对功率变化识别显著上升或下降事件。阈值为站点装机容量的 8%，且最低为 1 MW。
- **站点出力概览**：显示选中时刻的中心出力、未来窗口峰值、爬坡量和模型一致性。

页面默认纳入精选站点和通过“站点预测”新增的自定义站点。默认精选站点包括张北、酒泉、锡林郭勒、宁夏、青铜峡和通州，后续可以在不改变页面结构的情况下扩展为区域或企业站点组。

## API

`GET /api/power-outlook?hours=24&limit=12`

参数范围：

- `hours`：6–48，默认 24。
- `limit`：1–24，默认 12。

返回结构包含：

- `totals`：纳入容量、当前出力、下一小时爬坡、峰值和时间序列。
- `stations`：每个站点的元数据、中心出力、峰值、爬坡事件和时间序列。
- `alerts`：未来窗口内的爬坡预警，包含方向、MW、置信度和等级。
- `errors`：单模型请求失败时的降级信息。可用模型仍会参与集合计算。

后端在内存中缓存 5 分钟，单次请求最多并发读取 6 个站点预测任务。每个站点最多请求 GFS、GRAPES、IFS、AIFS 四个模型，模型暂时不可用时按剩余结果计算区间。

## 解释口径

当前的“集合一致性”是模型功率区间相对站点装机容量的反向评分，适合判断预报分歧，不等同于实际功率预测准确率。后续接入站点实测功率后，应增加滚动误差、校准区间和预测考核指标。

下一阶段可以接入实时负荷、输电通道和市场价格，把功率爬坡升级为送出压力、备用需求和弃风弃光风险。
