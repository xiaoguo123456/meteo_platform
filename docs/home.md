# 首页功能

## 省平均预报

首页地图点击位置后弹出单点预报；点在中国省级行政区内时，面板顶部可切换"单点 / 某省平均"。切换后地图描边高亮该省，曲线显示省内面积加权平均，浅色带为省内格点最低—最高范围，悬停显示该时刻平均、最低、最高及风向。省平均模式下再次点击地图会跟随切到所点省份，点到境外或海上回到单点；也可在面板下拉框直接换省。

### 统计口径

- 省域：`backend/app/data/province_regions.json`，由 GMT CN-border-La 面数据生成（34 个省级行政区，含岛屿外环与洞），来源与用途限制见 [省界来源](data-sources/boundary.md)。界河岛屿"中朝共有"不参与统计。
- 格点权重：每个格点 4×4 子采样估算落在省内的面积比例，再乘以 cos(纬度)，即经纬网格单元的实际面积占比；省界上的格点只按省内部分计入。
- 风速为各格点风速的加权平均，不是平均风矢量的模；风向取加权平均风矢量的方向。
- 缺测格点不参与该时刻统计。面积小于一个格点的省份（如澳门在 0.25° 网格）取离省域中心最近的格点，界面注明"面积小于网格，取最近格点"。
- 各模型网格与层次不同（GFS 为 80m 风、1000hPa 温湿，另三个为 10m 风、2m 温湿），省平均存在差异属正常。GFS 1000hPa 在高原地区位于地面以下，为外推值，西藏、青海、四川西部等省份的温度省平均需谨慎解读。

### 计算与发布

- 省份权重在首次使用时按模型网格计算并驻留内存，0.25° 与 0.125° 网格各约 0.2 秒。
- 预取每个时次时，全球数组已在内存中，顺带写出 `{时次}.provinces.json`（各省各要素的平均、最低、最高，风另含平均矢量），单帧约 10 毫秒。
- `provinces.json` 与 NPZ、浏览器数据块一起构成"该时次完成"的条件，因此沿用整批发布规则：新批次省平均未算完不会切换。
- 升级前已缓存的批次缺少该文件时，后台从本地 NPZ 补算，不重新下载；补算期间继续提供原批次，接口对缺文件的批次返回"省平均正在后台计算（x/y）"，前端 30 秒后自动重试。本地 GFS 实测 91 帧补算约 2.4 秒。
- 接口进程按模型、批次、要素缓存紧凑数组（帧 × 省 × 统计量），不缓存整帧字典。

### 接口

- `GET /api/provinces`：省份目录。
- `GET /api/provinces/locate?longitude=&latitude=`：所在省份，境外或海上返回 `null`。
- `GET /api/provinces/{code}/outline`：省域 MultiPolygon，用于地图高亮（只描边不填充）。
- `GET /api/province-forecast/{model}?code=&field=&run_time=`：整个预报时段的 `mean`、`min`、`max`（风另有 `direction`），附 `cells`、`nearest`、`resolution`、`level`、`unit`。

### 按省填色与全国排行

控制面板中点"各省对比"打开：格点色块隐藏（worker 只画底图与风矢量，风粒子照常），各省按当前时刻省平均填色，填色画在底层，风粒子与边界线在其上；同一张卡片列出全国排行前 5（最高/最低），点击打开该省的省平均面板。打开期间点地图直接打开所点省份的省平均（先查所在省份再打开面板，避免先闪一下单点），点到境外或海上仍看单点。卡片右上角 × 关闭，回到格点画面，点地图恢复看单点。分享链接以 `v=p` 记录。

- 数据：`GET /api/province-map/{model}?field=&run_time=&valid_time=` 读取该时刻已算好的 `provinces.json`，返回各省 `[平均, 最低, 最高]`；固定批次与时刻结果不变，浏览器缓存一天。切换时刻时保留上一帧填色，新数值到达后整体替换。
- 省域：`GET /api/provinces/shapes` 返回 `province_shapes.json`（0.01 度简化，约 70 万字节、gzip 后约 20 万字节），并附每省一个落在省内的标签点（按面积占比从大到小找中心在省内的格点，0.25° 找不到再用 0.125°），排行点击用它打开省平均。
- 环绕方向：d3-geo 球面填色要求外环顺时针、洞逆时针，否则会填满整个地球；转换脚本统一方向，前端测试用 `geoArea` 校验 34 省面积之和与国土面积一致。
- 色标：省平均抹平了极值，风速、降水省平均多在 0–20，按格点 0–50 的色标几乎同色，按省时把这两项色标压缩为 0–20，图例同步。
- GFS 温湿为 1000hPa，高原省份为外推值，排行最易误读，界面提示"排行仅供参考"。

第一版只做省级；地级市需要另行确定数据来源。

## 四模型对比

单点或省平均面板中点"四模型对比"，GFS、GRAPES、IFS、AIFS 四条曲线画在同一张图上；分享链接以 `c=1` 记录该状态。

- 每个模型读取自己最新的起报批次（`/api/models/{model}/runs`），再分别请求 `/api/point/{model}` 或 `/api/province-forecast/{model}`，后端无新增接口。
- 各模型起报时间与时间间隔不同（如 IFS 3 小时一帧），横轴按实际时刻对齐。悬停时各模型取离该时刻最近、相差不超过 1.5 小时的一帧。
- 底部总结"未来 24 小时 N 个模型最多相差 X"：从各模型共同起点起 24 小时内，只在各模型都恰有该时刻帧的整点比较（四模型都落在整点 UTC 上），至少两个模型有值才计算，不把相邻不同时刻的值相减。逻辑在 `frontend/src/compareMath.ts`。
- 图例标出各模型层次和起报时间。不提供该要素的模型（如 GFS 降水、云量）标"不提供该要素"，没有可用批次标"暂无可用预报"。
- GFS 的风为 80m、温湿为 1000hPa，与其他模型的 10m、2m 不同层次；对比风、温度、湿度时提示"GFS 高度与其他模型不同，仅供参考"。

## 首页分享链接

首页状态实时写入地址栏，复制给别人即可打开相同画面：

```
#home?m=ifs&f=cloud&t=2026-10-22T06:00Z&r=104.00,30.00&z=1.60&p=104.000,30.500&s=510000
```

| 参数 | 含义 |
|---|---|
| `m` | 模型：gfs、grapes、ifs、aifs |
| `f` | 要素：wind、temperature、humidity、pressure、precipitation、cloud；该模型不提供时退回第一个可用要素 |
| `t` | 预报有效时刻（UTC） |
| `r`、`z` | 视野中心经纬度与缩放（0.65–3） |
| `p` | 点击位置；有该参数时打开单点面板 |
| `s` | 省份代码；与 `p` 同时出现时打开该省平均 |
| `c` | 为 1 时打开四模型对比 |
| `v` | 为 p 时打开各省对比（按省填色与全国排行） |

- 只记预报时刻、不记起报批次。批次只保留两份，打开时若该时刻已不在当前批次，取最近一帧并提示"已切到最近时刻"。
- 用 `history.replaceState` 写回，不触发 `hashchange`，拖动时间轴不会塞满浏览器后退列表；链接里的时刻恢复前不写地址栏，避免覆盖原链接。
- 在已打开的首页粘贴新链接或前进后退到 `#home?` 时重新挂载首页读取参数。
- 非法或越界参数直接忽略。"复制分享链接"按钮已暂时移除（国内网络较慢），需要分享时直接复制浏览器地址栏即可。

## 一键导出动图

> 当前状态：国内访问线路较慢，界面入口已暂时移除；`frontend/src/exportVideo.ts` 与测试保留，日后接回控制面板即可恢复。以下为原设计。

控制面板"导出动图"：选择画幅（竖版 3:4 为 1080×1440，适合小红书；横版 16:9 为 1920×1080，适合公众号）和内容（当前时刻录 6 秒风粒子流动，或从当前时刻起未来 24/48/72 小时逐帧连播），点"开始导出"。全部在浏览器内完成，不占服务器资源。

- 合成：每个动画帧把地球的三层画布（底图与色块/按省填色、风粒子、边界线）裁成以地球为中心的正方形，画到导出画布上，叠加标题、模型·要素·层次、北京时间、起报时间、色标、数据来源和"晴川观象 · meteo.weishenai.cn"水印。放大到地球超出视口时导出的是屏幕上可见的部分。
- 录制：`canvas.captureStream(30)` + `MediaRecorder`，优先 MP4（H.264），不支持时（如 Firefox）退回 WebM 并提示；码率 8 Mbps，竖版 24 帧约 14 秒、约 15 MB。
- 逐帧：切到下一时刻后暂停录制，等地球容器的 `data-rendered` 标记显示该帧已完整画出（按省时还要等该时刻省平均到达）再录 0.6 秒，成片里不出现加载卡顿与空白；单帧加载超过 30 秒停止并提示。
- 后台：页面切到后台时浏览器停发动画帧，继续录会得到定格或过短的视频。隐藏期间自动暂停录制并提示，回到页面后继续；6 秒与每帧 0.6 秒都按实际录入时长计，而不是墙钟时间。
- 导出期间锁定控制面板（取消按钮除外），避免中途切换模型或要素打乱录制；离开首页时自动取消。
- 布局计算、格式选择与逐帧录制在 `frontend/src/exportVideo.ts`，测试覆盖格式回退与两种版式不越界。
