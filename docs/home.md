# 首页功能

## 省平均

点击地图弹出单点预报；点在中国省级行政区内时，面板顶部可切换「单点 / 某省平均」。省平均模式下地图描边高亮该省，曲线为省内面积加权平均，浅色带为省内最低—最高；再点地图会跟随切省，点到境外或海上回到单点。

统计口径：

- 省域：`backend/app/data/province_regions.json`（34 个省级行政区，含岛屿和洞），来源见 [省界来源](data-sources/boundary.md)。「中朝共有」界河岛屿不参与统计。
- 权重：每个格点 4×4 子采样估算落在省内的面积比例，再乘 cos(纬度)。
- 风速取各格点风速的加权平均；风向取加权平均风矢量的方向。
- 缺测格点不参与。面积小于一个格点的省份（如澳门）取离省中心最近的格点，界面注明。
- GFS 温湿为 1000hPa，高原省份（西藏、青海、川西等）是外推值，需谨慎解读。

计算与发布：

- 预取每个时次时顺带写出 `{时次}.provinces.json`（各省各要素的平均、最低、最高，风另含平均矢量），它与 NPZ、数据块一起算作「该时次完成」，所以新批次省平均没算完不会发布。
- 旧批次缺少该文件时后台从本地 NPZ 补算，期间接口返回「省平均正在后台计算（x/y）」，前端 30 秒后重试。

接口：

- `GET /api/provinces`：省份目录。
- `GET /api/provinces/locate?longitude=&latitude=`：所在省份，境外或海上返回 `null`。
- `GET /api/provinces/{code}/outline`：省域轮廓，用于高亮。
- `GET /api/province-forecast/{model}?code=&field=&run_time=`：整个预报时段的 `mean`、`min`、`max`（风另有 `direction`）。

## 各省对比

控制面板点「各省对比」：隐藏格点色块，各省按当前时刻省平均填色（风粒子照常），卡片列出全国最高/最低前 5，点击打开该省省平均。打开期间点地图直接打开所点省份的省平均。

- `GET /api/province-map/{model}?field=&run_time=&valid_time=`：各省 `[平均, 最低, 最高]`，浏览器缓存一天。
- `GET /api/provinces/shapes`：`province_shapes.json`（0.01 度简化），附每省一个落在省内的标签点。
- d3-geo 球面填色要求外环顺时针、洞逆时针，否则会填满整个地球；转换脚本已统一方向。
- 风速、降水的省平均多在 0–20，此模式下这两项色标压缩为 0–20。
- GFS 高原省份为外推值，界面提示「排行仅供参考」。

## 四模型对比

单点或省平均面板点「四模型对比」，GFS、GRAPES、IFS、AIFS 画在同一张图上。

- 每个模型取自己的最新批次，分别请求 `/api/point/{model}` 或 `/api/province-forecast/{model}`。
- 横轴按实际时刻对齐；悬停时各模型取最近且相差不超过 1.5 小时的一帧。
- 底部「未来 24 小时 N 个模型最多相差 X」只在各模型都恰有该时刻帧的整点比较，至少两个模型有值才算。逻辑在 `frontend/src/compareMath.ts`。
- 不提供该要素的模型标「不提供该要素」；对比风、温湿时提示 GFS 高度不同。

## 分享链接

首页状态实时写进地址栏，复制地址即可分享：

```
#home?m=ifs&f=cloud&t=2026-10-22T06:00Z&r=104.00,30.00&z=1.60&p=104.000,30.500&s=510000
```

| 参数 | 含义 |
|---|---|
| `m` | 模型：gfs、grapes、ifs、aifs |
| `f` | 要素：wind、temperature、humidity、pressure、precipitation、cloud；模型不提供时退回第一个可用要素 |
| `t` | 预报有效时刻（UTC） |
| `r`、`z` | 视野中心经纬度与缩放（0.65–3） |
| `p` | 点击位置，有则打开单点面板 |
| `s` | 省份代码，与 `p` 同时出现时打开省平均 |
| `c` | 1 = 打开四模型对比 |
| `v` | p = 打开各省对比 |

- 只记预报时刻、不记批次；该时刻不在当前批次时取最近一帧并提示。
- 用 `history.replaceState` 写回，不污染后退列表。非法参数直接忽略。

## 导出动图（入口已暂时移除）

`frontend/src/exportVideo.ts` 和测试仍保留，接回控制面板即可恢复。功能：选竖版 1080×1440 或横版 1920×1080，录当前时刻 6 秒风粒子，或从当前时刻起逐帧连播 24/48/72 小时；把地球三层画布合成到导出画布并叠加标题、时间、色标和水印，用 `MediaRecorder` 录成 MP4（不支持时退回 WebM）。逐帧模式等 `data-rendered` 标记确认该帧画完才录；页面切到后台时自动暂停录制。
