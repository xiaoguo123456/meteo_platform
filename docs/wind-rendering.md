# 风场渲染路线核验

2026-10-13 直接读取参考站 HTML 与公开 JavaScript，确认以下实现。首页已替换为 D3 正射投影 + 分层 Canvas；以下记录参考研究、实现范围与验收结果。

## 参考站的实际实现

参考：https://blog.1663457.xyz/earth/index.html

- `libs/earth/1.0.0/earth.js?v=17`：屏幕风场插值、球面遮罩、粒子生命周期和尾迹动画。
- `libs/earth/1.0.0/products.js?v=19`：规则网格重建、标量及 u/v 双线性插值、风速色标。
- `libs/earth/1.0.0/globes.js?v=16`：D3 地理投影，页面使用 orthographic 正射投影。
- `libs/earth/1.0.0/guanchao-data.js?v=18`：将站点 `/api/field` 返回结果适配为 earth 所需网格格式。仅能确认浏览器端适配，不能据此断言它的后端实现。

页面加载 D3 3.3.10、TopoJSON、Backbone 等依赖，而非 Globe.gl。渲染包含地图、粒子动画、标量底色和前景等独立层。

## 决定视觉效果的算法

1. 从屏幕坐标反投影到经纬度，利用邻近四个格点分别插值 u、v，再计算风速 sqrt(u²+v²)。
2. 对风向做投影畸变修正，将地理方向转换成屏幕方向；缓存屏幕风场，避免每个动画帧重复执行全量插值。
3. 逐像素生成风速底色。参考代码按 2×2 像素块填充；底色只依赖网格与视图，不依赖粒子位置。
4. 粒子在可见区域随机播种，每一步读取当前位置的风矢量。年龄超过 100 帧或离开有效区域后重新播种。
5. 使用 destination-in 对上一帧画布做约 0.97 的透明度衰减，再按速度分桶批量描线，形成连续尾迹。
6. 粒子数量约为投影可见区域宽度乘 7，移动端再乘 0.75。球宽 650 像素时约 4550 个，视觉密度主要来自空间分布与持续尾迹。
7. 拖动、缩放和切数据时停止旧动画、重建屏幕风场，避免尾迹错位。

## 旧版代码的根本问题

- 将百万级规则网格抽成散点后，丢失了连续风场拓扑。
- 粒子移动始终使用出生点的 u/v，没有沿途重新插值，不能正确形成涡旋和辐合。
- 复制采样点增加数量，导致成簇平行短线；没有合理的寿命与重播种，粒子会堆到极区。
- 每帧清空画布并只保留六个位置，导致尾迹过短；增加初始化尾迹长度只在开始数帧有效。
- 模糊圆斑随粒子移动，不能作为真实风速底色。
- 当前背面判断仅使用点积大于零，未正确处理透视相机的地平线遮挡。
- 构建通过、接口成功、控制台无报错都不等于气象展示正确。此前声称效果已接近参考页并无足够依据。

## 替换方案

先实现与参考一致的 D3 正射投影 + 分层 Canvas 渲染。React 保留控制面板，S3 保留为唯一正式数据源。停止继续调整旧粒子的数量、光斑和高度。

后端输出规则网格元数据和完整 0.25° u/v 二进制数组，包含经纬度起点、扫描方向、步长、缺测值、实际高度层和有效时间。两个全球 Float32 风分量约 8.3 MB（未压缩），按模型运行缓存并通过 HTTP 压缩传输；需要时再量化，不能以复制散点代替网格精度。先核实 S3 扫描方向与变量高度；当前 GFS 使用 80m 风，不能标作 10m 风。

前端用 Worker 完成反投影、双线性插值和风速底色生成；动画读取缓存的屏幕矢量场，按上述生命周期和衰减方式绘制。底色和风线分开，关闭动画时仍可查看静态色场。

优先复用 cambecc/earth 开源算法并核查、保留许可证与署名；不直接复制参考站定制业务代码。Globe.gl 可保留为后续三维模式，但不强行用其路径层重现这套效果。

## 验收条件

- 恒定风场方向正确，解析旋涡场轨迹随位置转弯，缺测区域无轨迹；验证日期变更线与极区。
- 底色在动画关闭时保持不动，色标数值与采样风速一致。
- 同视口比较参考页的球体尺度、细尾迹、连续色带；拖动和缩放后无漂浮、穿球或旧尾迹。
- 实测动画帧耗时与交互延迟，不把 30 FPS 的调度上限当成实际帧率。
- 断开 S3 明确报错，不改用合成数据或其他接口。

## 本次落地与验证

- `/api/wind/gfs` 提供完整 1440×721 的 Float32 u/v 网格，单帧 8,306,224 字节；响应包含真实有效时间与 80m 高度。只使用 S3，不调用预报 API、不生成替代风场。
- React 首页采用 `d3-geo`；Worker 完成反投影、双线性插值、投影方向变换、2×2 像素色场；主线程按当前位置屏幕矢量推进粒子、分桶描线并衰减尾迹。
- 视图变更立即清除旧线，80ms 防抖后重建；过期 Worker 结果按版本丢弃。关闭动画保留底色。
- 目前只开放核验过扫描方向的 GFS 最新一帧；其他模型返回明确错误。温度、气压、云图、多时次和正式省界尚未迁移到新渲染器，不能以占位控件表示已实现。
- 地图使用 Natural Earth 110m 海岸线，无政治国界。来源：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_coastline.geojson 。本次独立实现通用算法，没有复制参考站定制代码。
- 实际 S3 帧：2026-10-13T00:00Z；2,076,480 个分量值均有限，风速范围 0–42.51 m/s。
- 前端算法测试覆盖恒定场、经度回绕、南北极点、双线性插值、旋涡推进、缺测与色标。后端测试覆盖二进制布局、网格形状和 S3 异常透传；生产构建通过。
- 浏览器已观察到连续色带和弯曲尾迹，关闭动画后底色保留。调试耗时记录在 `.weather-globe` 的 data-fps、data-frame-cost-ms、data-field-build-ms 属性，不作为面向用户的界面文字。帧率受视口、后台节流和设备影响，不宣称固定 30 FPS。

## 界面与要素展示约定

- 产品名称：晴川观象。页面采用浅灰青背景、浅色控制面板和深色文字。
- 风场使用风速色带与可开关的流线动画。
- 温度、气压、湿度、降水等其他要素只用对应数值色带，不使用粒子或叠加风场动画；切换要素时同步更新色标、单位和高度层。其他要素的数据接入仍按上述实际范围推进。

## 要素与抗锯齿更新

- 风场默认播放，删除动画开关；温度、气压、湿度只显示独立数值色带。
- `/api/wind/gfs?field=temperature|pressure|humidity` 返回原生标量网格，沿用二进制布局，第二数组为零占位。温度、湿度为 1000hPa，气压为海平面；当前文件未提供降水，返回 503 中文提示。
- 实测温度 -39.3–40°C、海平面气压 950.1–1032.6hPa、相对湿度 7–100%。无可用降水时不以云量替代。
- 画布按设备像素比（最高 2 倍）绘制；Worker 色场外扩至边缘后，通过高分辨率圆形裁剪平滑边缘。保留屏幕场分辨率，避免将插值计算量放大四倍。

## 后台预取与预报时间轴（2026-10-13）

- API 生命周期启动后台任务，每 300 秒检查 S3 最新起报清单；同步失败后每 30 秒重试，错误保留在页面上直到同步恢复。长批次下载中也定期检查新起报；不由用户请求触发下载。
- 同一时刻的所有已接入要素一次读取并保存压缩 NPZ，按起报批次和时次组织。临时文件原子替换后才加入可用时间轴；重启跳过已缓存时次。
- `GET /api/models/gfs/runs` 返回真实起报时间、已就绪时次、总数及同步错误。`GET /api/wind/gfs?field=wind&run_time=...&valid_time=...` 只读本地文件；不支持的模型、缺失要素、未缓存时刻和失效起报请求明确报错。
- 首次启动没有可用旧批次时，后台显示整批缓存进度，完整批次才进入时间轴。已有批次遇到新起报时继续展示旧批次，待新批次全部时次和浏览器数据块准备完成后原子切换；前端每 10 秒更新清单，提前载入后续两帧，内存最多保存六帧；拖动会暂停播放，播放等待当前帧完成，末尾循环。
- 起报时间与预报有效时间均显式标注北京时间。切换数据保留观察视角；完整新批次到来后重置时间轴并暂停播放，避免混批，切换前不清空旧画面。
- 本地保留最近两个已发布批次，完成新批次后清理更早的本模块缓存。原始 S3 分块缓存也存于批次目录。单机部署只需一个 Uvicorn 进程；文件锁防止独立 Worker 重复执行。
- 可配置 `WEATHER_FORECAST_CACHE`（默认项目 `data/cache/forecasts`）、`WEATHER_POLL_SECONDS`（默认 300）。首次预取完整预报批次需要时间和磁盘，不表示全部时次立即可用。
- 回归测试覆盖后台预取、重启断点续传、接口禁止访问上游、不同预报时次内容不同、同步失败提示与未完成文件不发布。

实测最新 GFS 起报为 2026-10-13T00:00:00Z，清单含 209 个时次；已验证首帧与 +3 小时帧的 u 分量平均绝对差为 1.27m/s，时间轴切换不是重复首帧。完整批次在后台逐步缓存，尚未全部下载。

## 生产并发优化

默认两个时刻并发、256 KiB 分块；各时刻独立缓存目录，失败清理临时分块后重试一次。完成后删除原始分块，仅保留 NPZ。生产前 16 帧平均完成间隔约 5.75 秒，属于部署环境与并发优化的综合实测。部署说明见 deployment.md。


## 多模型上线更新

现已支持 GFS、IFS、AIFS、GRAPES 最新起报批次及各要素时间轴。以上首版范围记录为历史状态，以 deployment.md 为当前部署说明。新增模型使用真实 10m 风及 2m 温湿度；GRAPES 保留 0.125° 原生格心坐标。下载并发由 2 改为全模型共享 4 路，轮流优先下载近时效；每个模型独立报告错误。前端在切换模型时隔离旧批次，在切换要素时重置时间索引；降水显示时段并跳过缺测起报时刻。
