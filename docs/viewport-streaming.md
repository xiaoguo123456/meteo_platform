# 视野分块与动画缓存方案

## 方案比较

- [OpenLayers DataTile](https://openlayers.org/en/latest/apidoc/module-ol_DataTile.html)：瓦片可以携带 Float32 等数值数组，适合气象数据；无需把当前 D3 正射球面替换为 OpenLayers 才能采用这一模式。
- [Zarr 分块数组](https://zarr.readthedocs.io/en/latest/user-guide/arrays/)：按块读取、分片减少小文件，适合多维科学数据；本项目源文件已是 OM，当前单机不再引入第二套大型数组存储栈。
- [MapLibre 栅格源](https://maplibre.org/maplibre-style-spec/sources/)：标准图像金字塔便于显示，但风粒子需要原始 u/v。低层级降采样也不符合本次保持原始分辨率的要求。

选择：原生数值块 + 索引文件 + 视野流式读取 + 时序预缓冲。暂不生成低分辨率金字塔。GFS/IFS/AIFS 仍为 0.25°，GRAPES 仍为 0.125°，保持原始 Float32 值及缺测信息。

## 数据路径

每时刻、每要素按原网格切为 128×128 块，每块单独无损字典编码和 gzip；同一要素存为一个 `.v3.blocks` 文件及 `.v3.json` 偏移索引，避免数十万个小文件。后台预缓存时生成，老批次通过本地 NPZ 补建，不重新下载 S3。新批次在分块响应完成后才发布。

`GET /api/tiles/{model}?field=...&run_time=...&valid_time=...&tiles=...` 按请求顺序读取块。响应为重复的四字节小端长度 + gzip 数据块，禁用代理缓冲及二次压缩；浏览器使用 DecompressionStream 逐块解码，250ms 合并一次可见画面更新。固定批次响应可由浏览器 HTTP 缓存。

前端根据正射球面视野计算保守可见球冠，外扩块边缘及插值网格；按距离视野中心排序。拖动结束后只补取缺少的块。稀疏块直接参与原有双线性插值，不分配全球空数组。保留旧画面直到新块到达，缺失区域只显示真实底图，不填造气象数据。块缓存预算 192 MiB，最多保留 8 个完整视野帧。

## 动画

从当前时间顺序播放到整个可用预报的最后一帧后停止；在末尾再次播放会从头开始。后台滚动预取后续帧，不再限制或循环 8 帧片段。每帧至少展示 1.5 秒，下一帧完整下载后再切换；网络跟不上时保留当前画面并显示缓冲，不跳帧。新起报完整缓存后才更新对外时间轴，期间仍可播放上一批次；换批时暂停播放，新帧下载完成后替换旧画面。更换视野、模型、要素或手动拖动时间轴会停止播放。内存仍采用有界缓存，不把整个预报全部驻留内存。预取提升热缓存切换速度，但不保证冷加载或持续低带宽下每帧小于 1 秒。

## 实际边界

全地球视角仍要读取可见半球及外扩区域，不能承诺在低速网络上首帧或首次动画准备瞬间完成。主要收益是中心块先显示、背面不下载、局部缩放减少流量、相邻视野块复用、已缓冲动画连续播放。全球 276 块的 GRAPES 在 1000×700 测试视野下请求 183 块，放大 3 倍请求 35 块；具体数量随视野变化。

测试包括：分块拼回逐值一致、负值和缺测、日期变更线、极区、块接缝、可见区域不漏块，以及线上分块流首块/全响应耗时。

## 本次公网验收

在同一台开发机请求服务器的 GRAPES 温度数据：半球视野 183 块、2.133 MB，首块 0.913 秒、全部 3.873 秒；放大 3 倍 35 块、0.502 MB，首块 0.632 秒、全部 2.225 秒。属于单次链路实测，不作为所有模型、所有网络的性能保证。浏览器验证八帧缓冲后时间轴连续循环，并未使用插值伪造预报时次。

## v4 无损差分与要素预取

在每个原生块内对字典索引逐行做 uint16 模减差分，浏览器逐行累加还原；不量化、不改变任何原始 Float32 数值，包含缺测。接口增加 `version=4`，旧 `version=3` 保持兼容。后台对已有本地 NPZ 提前生成 `.v4.blocks` 与索引，新批次直接准备 v4；已有 v3 在旧批次清理前仍保留。

使用四模型实际首时刻全网格对比，v4 gzip 字典差分相对 v3 体积约减少 18%—27%：GFS 风场 1916203→1488756 字节，GRAPES 风场 5077562→3901178，GRAPES 温度 3308919→2575051。以上为编码体积试验，正式头部有少量额外字节，不代表端到端加载时间。

静止浏览时预取其他可用要素的首帧，加速用户切换；播放时只预取后续时刻，避免其他要素抢占带宽。逐块、逐行、日期变更线等原有验证继续适用；新增差分回绕、行边界、多通道、缺测值精确还原验证。

## 完整帧计时与压缩迁移修复

客户端记录从请求/播放需要该帧，到完整精细图像及边界提交画布的时间；渐进显示的局部块不计为完整帧。记录保存在地球元素的 `data-render-samples`，最多 120 帧，包含模型、要素、有效时间、总时间、等待时间、Worker 计算时间。固定 1.5 秒帧展示时间不计入切换延迟。

首轮 GFS 风场 40 帧：中位数 310 ms，P95 354 ms，1 帧超过 1 秒（网络缓冲 2119 ms）。同期 GRAPES 在后台压缩升级尚未完成时，40 帧中 10 帧超过 1 秒，中位数 339 ms、P95 4333 ms，不能用于声称稳定秒切。

已修正迁移路径：v4 尚未准备完成但本地 v3 完整时，直接返回同值旧编码，浏览器兼容解码；不读取上游、不造数据、不降分辨率，也不让交互请求等待重新编码。后台继续生成 v4。新增测试确保该路径不会调用本地快照解压重编码。29 项后端测试通过。

固定视角的经纬度反投影、底图采样和风矢量投影导数缓存复用，视野/尺寸/底图变化时失效；新增 Worker 测试逐像素对比缓存、要素切换、旋转后结果与全新计算一致。最终性能仍需以迁移修复部署后的浏览器记录为准。
