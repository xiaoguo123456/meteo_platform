# 首页分享链接

首页状态实时写入地址栏，复制给别人即可打开相同画面：

```
#home?m=ifs&f=cloud&t=2026-10-22T06:00Z&r=104.00,30.00&z=1.60&p=104.000,30.500&s=510000
```

| 参数 | 含义 |
|---|---|
| `m` | 模型：gfs、grapes、ifs、aifs |
| `f` | 要素：wind、temperature、humidity、pressure、precipitation、cloud；该模型不提供时退回第一个可用要素 |
| `t` | 预报有效时刻（UTC） |
| `r`、`z` | 视野中心经纬度与缩放（0.65–3） |
| `p` | 点击位置；有该参数时打开单点面板 |
| `s` | 省份代码；与 `p` 同时出现时打开该省平均 |
| `c` | 为 1 时打开四模型对比 |
| `v` | 为 p 时打开各省对比（按省填色与全国排行） |

- 只记预报时刻、不记起报批次。批次只保留两份，打开时若该时刻已不在当前批次，取最近一帧并提示"已切到最近时刻"。
- 用 `history.replaceState` 写回，不触发 `hashchange`，拖动时间轴不会塞满浏览器后退列表；链接里的时刻恢复前不写地址栏，避免覆盖原链接。
- 在已打开的首页粘贴新链接或前进后退到 `#home?` 时重新挂载首页读取参数。
- 非法或越界参数直接忽略。"复制分享链接"优先用剪贴板接口，被拒时退回旧式复制，仍失败则在面板中选中显示链接供手动复制。
